## 4. 对接注意事项

### 4.1 协议细节

#### 传输层
- 帧格式：4字节大端长度 + UTF-8 JSON payload
- 最大payload：16MB
- 粘包/半包：服务端已处理，客户端需参考 `FrameCodec` 实现

#### 消息外壳
- 请求：`{action, requestId, data}`
- 响应：`{requestId, code, message, data}`
- **重要**：`requestId` 由客户端生成，服务端原样返回用于匹配

#### 错误码
| code | 常量名 | 含义 | 客户端处理 |
|------|--------|------|-----------|
| 0 | CodeOk | 成功 | 正常处理data |
| 1001 | CodeBadRequest | 参数错误 | 弹窗提示message |
| 1002 | CodeUserFrozen | 账号冻结 | 强制登出 |
| 1003 | CodeNotLoggedIn | 未登录 | 跳转登录页 |
| 1101 | CodeAdminAuthFailed | 管理员认证失败 | 提示账号或密码错误 |
| 2001 | CodeChargerUnavailable | 桩不可用 | 提示选择其他桩 |
| 2002 | CodeBalanceInsufficient | 余额不足 | 提示充值 |
| 2003 | CodeOrderConflict | 订单冲突 | 提示刷新订单 |
| 5000 | CodeServerError | 服务端错误 | 提示稍后重试 |

### 4.2 会话管理（重要！）

- **协议无token**：身份认证靠连接绑定
- **登录后绑定**：`user.login` 或 `admin.login` 成功后，服务端将userId/adminId绑定到TCP连接
- **断连即登出**：连接断开后会话失效，需重新登录
- **并发限制**：同一用户可以多连接登录（服务端不限制）

**客户端实现建议**：
- 持久化手机号，启动时自动重新登录
- 检测连接断开，自动重连+重新登录
- 不要依赖"记住密码"（协议无密码字段）

### 4.3 字段对齐

#### user.login 响应
```json
{
  "userId": 123,
  "phone": "13800138000",
  "nickname": "用户8000",
  "avatar": "",  // data-URL或空字符串
  "balance": 100.50,
  "status": 0    // 0=正常, 1=冻结
}
```

#### station.nearby 响应
```json
{
  "stations": [
    {
      "stationId": 1,
      "name": "站点名",
      "address": "地址",
      "latitude": 39.9100,
      "longitude": 116.4200,
      "distance": 1234,        // 单位：米
      "availableCount": 5,     // 空闲桩数量
      "totalCount": 10         // 总桩数
    }
  ]
}
```

#### station.detail 响应
```json
{
  "stationId": 1,
  "name": "站点名",
  "address": "地址",
  "latitude": 39.9100,
  "longitude": 116.4200,
  "pricePerKwh": 1.50,
  "availableCount": 5,
  "totalCount": 10,
  "chargers": [
    {
      "chargerId": 101,
      "code": "A01",           // 桩编码
      "type": 0,               // 0=快充, 1=慢充
      "status": 0,             // 0=空闲, 1=充电中, 2=故障, 3=离线
      "powerKw": 120.0         // 额定功率
    }
  ]
}
```

### 4.4 头像方案

- **格式**：data-URL（`data:image/png;base64,iVBORw0KGgo...`）
- **大小限制**：≤256KB
- **客户端责任**：压缩、缩放（建议≤160px）
- **服务端存储**：原样存储在数据库TEXT字段，不解析不转存
