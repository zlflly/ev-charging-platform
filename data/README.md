# 数据目录说明

## 目录结构

- `raw/` - 原始数据存放位置（从数据库导出的订单、站点、桩数据）
- `processed/` - 预处理后的数据（时间序列特征、训练集、测试集）

## 数据说明

### 原始数据来源
数据由成员1（服务端负责人）提供，主要包括：
- 订单数据（orders）
- 站点数据（stations）
- 充电桩数据（chargers）
- 用户数据（users）

### 数据不纳入版本控制
由于数据文件可能较大，`data/raw/` 和 `data/processed/` 中的数据文件不提交到 git。
仅提交数据处理脚本和样例数据结构说明。
