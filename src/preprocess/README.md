# 数据预处理模块

## 功能说明

将原始订单数据转换成机器学习可用的时间序列特征数据集。

## 核心功能

### 1. 数据加载
- 从 SQLite 数据库读取订单和站点数据
- 只选择已完成的订单（status='completed'）
- 过滤掉缺失关键字段的记录

### 2. 按小时聚合
将订单数据按站点和小时聚合，计算：
- `order_count`: 该小时的订单数
- `total_energy`: 该小时的总充电量（kWh）
- `active_chargers`: 该小时在用的充电桩数（去重）
- `total_amount`: 该小时的总金额

### 3. 时间特征
- `hour`: 小时（0-23）
- `weekday`: 星期几（0=周一，6=周日）
- `day_of_month`: 每月第几天
- `month`: 月份
- `is_weekend`: 是否周末（0/1）
- `hour_sin`, `hour_cos`: 小时的周期性编码

### 4. 滞后特征（Lag Features）
用于捕捉时间序列的自相关性：
- `energy_lag_1`: 上一小时的充电量
- `energy_lag_6`: 6小时前的充电量
- `energy_lag_24`: 24小时前的充电量（昨天同一时刻）

### 5. 滚动统计特征
- `energy_rolling_mean_3`: 过去3小时的平均充电量

## 使用方法

### 运行预处理
```bash
python src/preprocess/preprocess_simple.py
```

### 输出文件
- `data/processed/hourly_features_simple.csv`: 处理后的特征数据

## 技术说明

### 为什么使用滞后特征？
充电负荷具有时间相关性：
- 上一小时的充电量可以预测下一小时
- 昨天同一时刻的充电量反映日周期性

### 为什么使用周期性编码？
使用 sin/cos 编码而不是直接用数字，可以让模型理解：
- 23点和0点是相邻的（不是相差23）
- 周日和周一是相邻的

### 缺失值处理
- 没有订单的小时：充电量填充为0（表示该时段无充电）
- 历史数据不足的滞后特征：填充为0（前几个小时）
