# 模型训练模块

## 功能说明

训练基线模型和机器学习模型来预测充电站的充电负荷。

## 训练的模型

### 1. 基线模型（用于对比）

#### Baseline-Lag1
- **策略**：预测值 = 上一小时的充电量
- **MAE**: 120.40 kWh
- **RMSE**: 162.50 kWh
- **用途**：最简单的基线，用于判断ML模型是否有提升

#### Baseline-Lag24
- **策略**：预测值 = 昨天同一时刻的充电量
- **MAE**: 123.48 kWh
- **RMSE**: 159.25 kWh
- **用途**：利用日周期性的基线

### 2. 机器学习模型

#### SimpleDecisionTree
- **算法**：简化版决策树回归器
- **MAE**: 96.21 kWh ✨ **最佳**
- **RMSE**: 128.51 kWh
- **特点**：
  - 比基线模型 MAE 降低了 20%
  - 能捕捉特征之间的非线性关系
  - 不依赖 sklearn，使用 Python 标准库实现

## 模型性能分析

### 为什么 MAE 比较高？

MAE = 96.21 kWh 看起来比较大，但考虑到：
- 平均充电负荷范围：0-300 kWh/小时
- 相对误差（MAPE）：89%

这是**第一版模型**，性能有提升空间。

### 改进方向

1. **增加数据量**
   - 当前只有30天数据，数据量偏少
   - 建议至少3个月以上的历史数据

2. **添加更多特征**
   - 天气数据（温度、降雨）
   - 节假日标记
   - 附近事件（大型活动）

3. **使用更复杂的模型**
   - GradientBoosting
   - LSTM（时间序列神经网络）
   - 集成模型

4. **针对不同站点分别训练**
   - 每个站点的特点可能不同
   - 分站点模型可能更准确

## 评估指标说明

### MAE (Mean Absolute Error)
- **含义**: 预测值与真实值的平均绝对误差
- **单位**: kWh
- **越小越好**

### RMSE (Root Mean Squared Error)
- **含义**: 预测值与真实值的均方根误差
- **单位**: kWh
- **对大误差更敏感**

### MAPE (Mean Absolute Percentage Error)
- **含义**: 平均绝对百分比误差
- **单位**: %
- **相对误差指标**

### R² (R-squared)
- **含义**: 决定系数，表示模型拟合优度
- **范围**: -∞ 到 1
- **1 表示完美拟合，0 表示与均值相当，负数表示比均值还差**

## 技术说明

### 为什么不用 sklearn？

第一版使用简化版决策树，原因：
1. 减少依赖，避免安装问题
2. 代码可读性强，易于理解
3. 足够证明模型训练能力

后续版本可以引入 sklearn 获得更好性能。

### 模型保存格式

使用 Python 的 pickle 格式保存，包含：
- 决策树结构
- 特征名称
- 模型参数

### 预测流程

```python
# 1. 加载模型
with open('models/load_forecasting_model.pkl', 'rb') as f:
    model = pickle.load(f)

# 2. 准备特征
features = {
    'hour': 8,
    'energy_lag_1': 150.0,
    ...
}

# 3. 预测
prediction = model.predict([features])[0]
print(f"预测充电负荷: {prediction:.2f} kWh")
```
